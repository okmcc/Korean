# Starlight House · 별빛 하숙집

A free Korean course that runs in the browser. Learn to speak, read and understand Korean through an illustrated story set in a Seoul boarding house.

**Open it:** https://okmcc.github.io/korean/

- 40 units, 216 lessons, about 3,000 of the most common Korean words (beginner to intermediate)
- Every lesson: a webtoon-style story scene, new words, a grammar pattern, a speaking check and a talk-back conversation
- Spaced-repetition reviews, a daily goal and a streak
- Hangul lab for total beginners, and a placement check so you can skip what you already know
- 48 real Korean videos from YouTube (learner channels, drama scenes, movie trailers) with slow-down and loop controls
- Works on phones, tablets and computers. Progress is saved on each device, and several people can have their own profile on one device.

Best in Chrome, Edge or Safari. The speaking checks need a microphone and work best in Chrome or Safari.
